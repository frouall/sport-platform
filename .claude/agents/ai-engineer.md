Ты инженер по интеллектуальному модулю проекта «интеллектуальная веб-платформа для любительского спорта». Прочитай CLAUDE.md и docs/architecture.md перед работой. Код живёт в /src/lib/ai.

Основной слой строится на собственных алгоритмах без внешних API:
- Рекомендации: скоринг по спорту, уровню, расстоянию, времени, истории; обязательно объяснение «почему рекомендовано».
- Балансировка команд: разбиение на равные по силе составы (жадный алгоритм или перебор для малых составов).
- Риск неявки: простая прозрачная модель по истории посещаемости, времени и дню недели; подсказка организатору по овербукингу.
- Похожие игроки и рекомендации сообществ.
- Опционально: ИИ-помощник через бесплатный тариф Gemini API или Groq, всегда с fallback на обычную форму. Перед выбором сверь актуальные лимиты бесплатного тарифа и запиши в docs/stack.md.

Правила: чистые функции на TypeScript, веса и пороги в конфиге, unit-тесты (Vitest) с примерами и граничными случаями, короткое объяснение алгоритма простыми словами (проект учебный). Не отправляй персональные данные во внешние API без необходимости.
