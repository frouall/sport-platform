# Стек и лимиты бесплатных тарифов

Проверено 2026-10-26 по официальным страницам. Лимиты могут измениться, перед релизом проверить заново.

## Выбранный стек (всё бесплатно)

| Слой | Технология |
|---|---|
| Frontend | Next.js (App Router), TypeScript strict, Tailwind CSS, shadcn/ui |
| Backend и БД | Supabase Free: PostgreSQL, Auth, RLS, Realtime, Storage |
| Карты | Leaflet + OpenStreetMap (без ключей API) |
| Хостинг | Vercel Hobby (или Cloudflare Pages) |
| ИИ | Собственные алгоритмы; опционально Gemini API / Groq (free tier) с fallback |
| Тесты и CI | Vitest, Playwright, GitHub Actions |

## Supabase Free

Источник: https://supabase.com/pricing

| Параметр | Лимит |
|---|---|
| База данных | 500 МБ на проект |
| Файловое хранилище | 1 ГБ |
| Исходящий трафик | 5 ГБ |
| Активные пользователи в месяц | 50 000 |
| Одновременные Realtime-подключения | 200 |
| Realtime-сообщения | 2 млн в месяц |
| Активных проектов | 2 |
| Пауза при простое | через 1 неделю неактивности |

Что это значит для проекта:
- Проект ставится на паузу после недели без активности. Перед защитой диплома зайти в панель и проверить, что он активен, а для демо заранее «разбудить» его.
- Требование карты на странице не указано. Если при создании проекта просят карту, остановиться и не вводить её.
- 500 МБ хватит для учебного проекта. Фото хранить в Storage с ограничением размера.

## Vercel Hobby

Источник: https://docs.vercel.com/docs/limits

| Параметр | Лимит |
|---|---|
| Fast Data Transfer | 100 ГБ |
| Fast Origin Transfer | до 10 ГБ |
| Вызовы функций | 1 млн |
| Время сборки | 100 часов |
| Одна сборка | не более 45 минут |
| Деплоев в сутки | 100 |

Открытый вопрос: условия коммерческого использования на странице лимитов не описаны. Для учебного проекта это не критично, но в условиях использования Vercel стоит прочитать отдельно.

## Не проверено (проверить перед использованием)

- Лимиты бесплатного тарифа Gemini API и Groq (нужны только для опционального ИИ-помощника).
- Бесплатный SMTP для email-уведомлений (Этап 4).
- Лимиты GitHub Actions для приватных репозиториев (для публичных они не ограничены по минутам).
